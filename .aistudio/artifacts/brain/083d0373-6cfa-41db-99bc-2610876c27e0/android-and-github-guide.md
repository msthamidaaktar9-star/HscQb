# 📱 Zero-Terminal Android & GitHub Actions APK Guide
*(অ্যান্ড্রয়েড ফোন থেকে কোনো টার্মিনাল কমান্ড ছাড়াই সরাসরি APK বিল্ড ও ডেটাবেস ব্যবহার)*

আপনি যদি শুধুমাত্র একটি **অ্যান্ড্রয়েড ফোন** ব্যবহার করেন এবং কম্পিউটারে কোনো টার্মিনাল বা কোডিং কমান্ড দিতে না চান, তবে নিচের সহজ ধাপগুলো অনুসরণ করুন। গিটহাবের ক্লাউড সার্ভার সম্পূর্ণ স্বয়ংক্রিয়ভাবে আপনার জন্য **Android APK** তৈরি করে দেবে।

---

## 🚀 উপায় ১: গিটহাব অ্যাকশন দিয়ে মোবাইল থেকেই সরাসরি APK বিল্ড (Zero Terminal)

এই রিপোজিটরির ভেতরে **`.github/workflows/build-apk.yml`** ফাইলটি যুক্ত করা আছে। এর ফলে কোনো টার্মিনাল ছাড়া শুধু মোবাইল ক্রোম ব্রাউজার দিয়েই কাজ করা সম্ভব:

### ধাপ ১: GitHub-এ ফাইল আপলোড করুন
1. আপনার ফোনে **Google Chrome** খুলে [github.com](https://github.com)-এ লগইন করুন।
2. **"New repository"** বাটনে ট্যাপ করে একটি নতুন রিপোজিটরি তৈরি করুন (যেমন: `physics-qb`).
3. রিপোজিটরি পেজে ঢুকে **"Add file" > "Upload files"** বাটনে ট্যাপ করুন।
4. আমাদের দেওয়া প্রজেক্টের সমস্ত ফাইল সিলেক্ট করে আপলোড করুন এবং নিচে থাকা সবুজ **"Commit changes"** বাটনে চাপ দিন।

### ধাপ ২: GitHub Actions স্বয়ংক্রিয়ভাবে বিল্ড শুরু করবে
1. আপনার রিপোজিটরির উপরের মেনু থেকে **"Actions"** ট্যাবে যান।
2. দেখতে পাবেন **"Build Android APK (অটোমেটিক অ্যান্ড্রয়েড APK বিল্ডার)"** নামের একটি ওয়ার্কফ্লো ক্লাউডে চলা শুরু হয়েছে।
3. *(অথবা Actions ট্যাবে গিয়ে **Build Android APK > Run workflow** বাটনে একবার ট্যাপ করলেই হবে।)*
4. গিটহাবের সার্ভার স্বয়ংক্রিয়ভাবে Java 17, Android SDK এবং Gradle চালু করে APK তৈরি করবে (এতে ৩-৫ মিনিট সময় লাগে)।

### ধাপ ৩: সরাসরি ফোনে APK ডাউনলোড ও ইন্সটল
1. অ্যাকশনটি সম্পন্ন হলে নামের পাশে সবুজ টিকচিহ্ন (✅) আসবে।
2. ওই বিল্ডের নামের উপর ক্লিক করে নিচের দিকে নামুন।
3. **"Artifacts"** সেকশনে দেখতে পাবেন:  
   👉 **`Uddvash-Physics-Question-Bank-APK`** (অথবা Releases সেকশনে `v1.0.0`)
4. ফাইলটিতে ট্যাপ করলেই সরাসরি আপনার ফোনে **`app-debug.apk`** ডাউনলোড হয়ে যাবে!
5. ডাউনলোডের পর ট্যাপ করে ইন্সটল করুন এবং সম্পূর্ণ অফলাইনে ব্যবহার উপভোগ করুন।

## 🗄️ উপায় ২: SQLite (`.db` ও `.sql`) ডেটাবেস সাপোর্ট

আপনার প্রশ্নের প্রেক্ষিতে আমরা অ্যাপ্লিকেশনটিতে **SQLite ও SQL ডাটাবেস স্ক্রিপ্ট সাপোর্ট** যুক্ত করেছি:

1. **`question-database.sql` ফাইল:**
   - এটি একটি সম্পূর্ণ রিলেশনাল ডাটাবেস স্ক্রিপ্ট (`CREATE TABLE questions (...)` এবং সব প্রশ্নের `INSERT` কুয়েরি)।
   - এটি যেকোনো **SQLite (.db)** ফাইল, Android Room Database, PostgreSQL অথবা MySQL-এ সরাসরি রান বা ইমপোর্ট করা যায়।
2. **মোবাইল থেকেই ডাউনলোড:**
   - অ্যাপের ওপরের হেডারে থাকা **"ফাইল ডাউনলোড (Offline HTML)"** বাটনে ট্যাপ করুন।
   - সেখানে থাকা **`SQLite (.sql / .db)`** বাটনে ক্লিক করলে আপনার ফোনে সম্পূর্ণ ডেটাবেস স্ক্রিপ্ট ডাউনলোড হয়ে যাবে।
   - এটি **Artifacts** প্যানেলেও **`question-database.sql`** নামে যুক্ত রয়েছে।

## ⚡ উপায় ৩: কোনো বিল্ড ছাড়াই সরাসরি অফলাইন এইচটিএমএল (সবচেয়ে দ্রুত)

আপনি যদি কোনো APK বিল্ডের ঝামেলাতেও যেতে না চান:
1. প্রিভিউ স্ক্রিন থেকে **"ফাইল ডাউনলোড (Offline HTML)"** > **"HTML ডাউনলোড (.html)"** বাটনে ক্লিক করে **`uddvash-physics-question-bank.html`** নামিয়ে নিন।
2. ফোনে **Airplane Mode (ইন্টারনেট বন্ধ)** চালু করুন।
3. আপনার ফোনের **Files** অ্যাপ থেকে ফাইলটি Chrome-এ ওপেন করুন।
4. ব্যস! একটি পূর্ণাঙ্গ মোবাইল অ্যাপের মতোই অফলাইনে উদ্ভাস ২-কলাম ভিউ, প্র্যাকটিস কুইজ ও প্রিন্ট কার্যকর থাকবে।
